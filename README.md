# SauceDemo Autotests

Проект автоматизации тестирования сайта SauceDemo, включающий UI- и API-тесты, а также встроенный веб-интерфейс для управления тестами, работы с логами и Git.

## Стек
Java 17, Maven, Selenium WebDriver, TestNG, Page Object Model, Allure, Rest Assured.

## Реализованные авто-тесты
* UI-тест TC-AUTH-001: Успешная авторизация пользователя standard_user. Проверка перехода на inventory.html, заголовка Products и отображения списка товаров. К тесту прилагается скриншот в отчете Allure.
* API-тест API-001: Проверка доступности главной страницы SauceDemo через HTTP GET. Проверка кода ответа 200 и наличия текста Swag Labs.

## Веб-интерфейс (WebUi)
Проект имеет встроенный веб-сервер (порт 8080), который автоматически определяет среду запуска (Local или Docker) и выводит это в заголовке страницы. Доступные функции:
* Запуск выбранных тестов с отображением лога в реальном времени.
* Кнопка "Копировать лог": перед копированием в буфер обмена выполняется обезличивание лога в целях безопасности (скрываются локальные пути, логины, пароли, IP и email).
* Кнопка "Очистить лог": сбрасывает текущий лог.
* Кнопка "->Git" (доступна только в Local): проверяет статус Git, формирует коммит-сообщение со списком измененных файлов и выполняет git add, commit, push.
* Кнопка "->Docker" (доступна только в Local): раскомментирует headless-режим в DriverFactory.java, собирает Docker-образ, возвращает файл в исходное состояние и открывает окно cmd с командой для ручного запуска контейнера.
* Просмотр отчета Allure: ссылка на сгенерированный отчет.

## Утилиты для работы с дампами проекта
* list_code_project.py: генерирует обезличенный дамп проекта (project_dump.txt) и файл словаря с оригинальными значениями (project_dump_keys.txt). В целях безопасности и защиты конфиденциальной информации выполняет обезличивание, заменяя критичные данные на уникальные метки.
* restore_project.py: восстанавливает проект из обезличенного дампа, используя файл ключей для обратной замены меток на оригинальные данные.

## Запуск локально
mvn clean test
mvn allure:report

Для запуска веб-интерфейса используйте run_webui.bat или выполните:
java WebUi.java

## Запуск в Docker
docker build -t saucedemo-autotests .
docker run --rm -p 8080:8080 saucedemo-autotests

## CI/CD
Настроен GitHub Actions (.github/workflows/daily_run.yml).
Запуск происходит ежедневно в 06:00 МСК, а также доступен ручной запуск.
Отчет публикуется на GitHub Pages: https://terebok.github.io/demo_JavaSelenium/
Уведомление о результате приходит в виде GitHub Issue с назначением исполнителя.

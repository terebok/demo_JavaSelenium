тестирование: Java, Selenium
Тестирование веб-приложений с помощью Java и Selenium — это один из самых востребованных и надежных подходов в автоматизации. Selenium WebDriver предоставляет мощный API для управления браузером, а Java обеспечивает производительность, стабильность и богатую экосистему для создания масштабируемых тестовых фреймворков.

🛠️ Настройка окружения и первый тест
Для начала работы необходимо подготовить инструменты. Современный подход сводит ручную настройку к минимуму.

Установите JDK (Java Development Kit): Это основа для компиляции и запуска вашего Java-кода.

Выберите IDE: IntelliJ IDEA (Community Edition) или Eclipse — популярные среды разработки, которые упрощают написание и отладку тестов.

Создайте Maven-проект: Maven автоматически управляет зависимостями. В файл pom.xml нужно добавить зависимость selenium-java:

xml
<dependency>
    <groupId>org.seleniumhq.selenium</groupId>
    <artifactId>selenium-java</artifactId>
    <version>4.30.0</version> <!-- Укажите актуальную версию -->
</dependency>
Управление драйверами: Начиная с Selenium 4.6, вам не нужно вручную скачивать драйверы для браузеров. Selenium Manager автоматически найдет, скачает и настроит нужный драйвер (например, ChromeDriver).

Пример простого скрипта, который открывает браузер, вводит текст и закрывает его:

java
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;
import java.time.Duration;

public class FirstScript {
    public static void main(String[] args) {
        // Selenium Manager автоматически настроит драйвер
        WebDriver driver = new ChromeDriver();
        try {
            driver.get("https://www.selenium.dev/selenium/web/web-form.html");
            // Установка неявного ожидания
            driver.manage().timeouts().implicitlyWait(Duration.ofMillis(500));

            WebElement textBox = driver.findElement(By.name("my-text"));
            WebElement submitButton = driver.findElement(By.cssSelector("button"));

            textBox.sendKeys("Selenium");
            submitButton.click();

            WebElement message = driver.findElement(By.id("message"));
            System.out.println("Текст сообщения: " + message.getText());
        } finally {
            driver.quit(); // Важно закрывать браузер
        }
    }
}
🔑 Ключевые концепции и инструменты
Поиск элементов (Локаторы)
Чтобы взаимодействовать с веб-страницей, нужно находить ее элементы. Selenium поддерживает различные стратегии поиска (By.id, By.name, By.className, By.cssSelector, By.xpath). Рекомендуется использовать стабильные и уникальные локаторы, в первую очередь ID и CSS-селекторы, и избегать хрупких XPath-выражений, привязанных к структуре DOM.

Ожидания (Waits) — борьба с «нестабильными» тестами
Современные веб-приложения динамичны, и элементы могут появляться не мгновенно. Никогда не используйте Thread.sleep() — это делает тесты медленными и ненадежными. Вместо этого применяйте:

Неявные ожидания (Implicit Waits): Устанавливают глобальный тайм-аут для поиска любого элемента. Используется как базовый предохранитель.

Явные ожидания (Explicit Waits): Это рекомендуемый подход. Они позволяют ждать выполнения конкретного условия для конкретного элемента (например, его кликабельности или видимости). WebDriverWait в связке с ExpectedConditions делает тесты быстрыми и стабильными.

Пример явного ожидания:

java
import org.openqa.selenium.support.ui.WebDriverWait;
import org.openqa.selenium.support.ui.ExpectedConditions;
import java.time.Duration;

WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
WebElement element = wait.until(ExpectedConditions.visibilityOfElementLocated(By.id("myElement")));

package com.saucedemo.pages;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;

import java.time.Duration;

public class LoginPage {

    private final WebDriver driver;
    private final WebDriverWait wait;

    private final By usernameField = By.id("user-name");
    private final By passwordField = By.id("password");
    private final By loginButton = By.id("login-button");
    private final By errorMessage = By.cssSelector("[data-test='error']");

    public LoginPage(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }

    public LoginPage open(String url) {
        driver.get(url);
        wait.until(ExpectedConditions.visibilityOfElementLocated(usernameField));
        return this;
    }

    public LoginPage enterUsername(String username) {
        WebElement field = wait.until(ExpectedConditions.visibilityOfElementLocated(usernameField));
        field.clear();
        field.sendKeys(username);
        return this;
    }

    public LoginPage enterPassword(String password) {
        WebElement field = wait.until(ExpectedConditions.visibilityOfElementLocated(passwordField));
        field.clear();
        field.sendKeys(password);
        return this;
    }

    public InventoryPage clickLogin() {
        wait.until(ExpectedConditions.elementToBeClickable(loginButton)).click();
        return new InventoryPage(driver);
    }

    public String getErrorMessage() {
        return wait.until(ExpectedConditions.visibilityOfElementLocated(errorMessage)).getText();
    }
}

package com.saucedemo.pages;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;

import java.time.Duration;

public class InventoryPage {

    private final WebDriver driver;
    private final WebDriverWait wait;

    private final By pageTitle = By.className("title");
    private final By inventoryList = By.className("inventory_list");

    public InventoryPage(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }

    public String getPageTitle() {
        return wait.until(ExpectedConditions.visibilityOfElementLocated(pageTitle)).getText();
    }

    public boolean isInventoryListDisplayed() {
        return wait.until(ExpectedConditions.visibilityOfElementLocated(inventoryList)).isDisplayed();
    }

    public String getCurrentUrl() {
        return driver.getCurrentUrl();
    }
}

package com.saucedemo.utils;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.chrome.ChromeOptions;

public class DriverFactory {

    public static WebDriver createDriver() {
        ChromeOptions options = new ChromeOptions();
        options.addArguments("--start-maximized");
        options.addArguments("--disable-notifications");
        return new ChromeDriver(options);
    }

    public static void quitDriver(WebDriver driver) {
        if (driver != null) {
            driver.quit();
        }
    }
}

Пошаговая инструкция по настройке автоматического открытия отчета Allure в браузере после прогона тестов.

Вариант 1. Использование команды allure:serve (наиболее простой)
Шаг 1. Вместо команды mvn test для запуска тестов используйте команду:
mvn allure:serve

Шаг 2. Данная команда генерирует отчет и запускает локальный веб-сервер, после чего автоматически открывает главную страницу отчета в браузере по умолчанию. Для остановки сервера нажмите Ctrl+C в терминале.

Вариант 2. Автоматическая генерация отчета при сборке (через pom.xml)
Шаг 1. Откройте файл pom.xml в каталоге C:\AT_Project\demo_JavaSelenium.

Шаг 2. В секции <build> внутри <plugins> добавьте следующий блок плагина allure-maven:

xml
<plugin>
    <groupId>io.qameta.allure</groupId>
    <artifactId>allure-maven</artifactId>
    <version>2.15.0</version>
    <configuration>
        <reportVersion>${allure.version}</reportVersion>
        <resultsDirectory>${project.build.directory}/allure-results</resultsDirectory>
    </configuration>
    <executions>
        <execution>
            <phase>verify</phase>
            <goals>
                <goal>report</goal>
            </goals>
        </execution>
    </executions>
</plugin>
Шаг 3. После добавления плагина запускайте тесты командой mvn verify вместо mvn test. Отчет будет автоматически сгенерирован в каталог target/site/allure-maven-plugin/index.html.

Шаг 4. Для автоматического открытия сгенерированного отчета в браузере используйте команду mvn allure:serve (она откроет отчет после генерации) либо настройте свойство allure.automaticallyOpen (по умолчанию имеет значение true).

Вариант 3. Генерация отчета в виде одного HTML-файла
Шаг 1. Если требуется один самодостаточный HTML-файл, который можно открыть без веб-сервера, добавьте в конфигурацию плагина параметр <singleFile>true</singleFile>.

Шаг 2. После выполнения mvn verify отчет будет создан в target/site/allure-maven-plugin/index.html и может быть открыт в браузере напрямую.

что нужно сделать для упаковки в докер контейнер
Для упаковки проекта в Docker-контейнер необходимо выполнить следующие действия. Создать в корневом каталоге проекта файл с именем Dockerfile. В Dockerfile указать базовый образ, содержащий JDK и Maven, например maven:3.9.6-eclipse-temurin-17. В Dockerfile выполнить установку браузера Google Chrome и ChromeDriver, либо использовать готовый образ selenium/standalone-chrome, который уже включает Java, Selenium и Chrome. Скопировать файлы проекта (pom.xml, testng.xml, каталог src) в рабочий каталог контейнера. // Импорт встроенного HTTP-сервера из JDK
import com.sun.net.httpserver.HttpServer;
// Импорт класса для обработки HTTP-запросов
import com.sun.net.httpserver.HttpHandler;
// Импорт класса для обмена данными
import com.sun.net.httpserver.HttpExchange;
// Импорт для работы с сетевым адресом
import java.net.InetSocketAddress;
// Импорт для чтения тела запроса и записи ответа
import java.io.*;
// Импорт для кодировки UTF-8
import java.nio.charset.StandardCharsets;

// Главный класс веб-интерфейса
public class WebUi {

    // Флаг: выполняется ли сейчас прогон тестов
    private static volatile boolean running = false;

    // Точка входа
    public static void main(String[] args) throws Exception {
        // Создание HTTP-сервера на порту 8080
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        // Обработчик главной страницы
        server.createContext("/", WebUi::handleIndex);
        // Обработчик запуска тестов
        server.createContext("/run", WebUi::handleRun);
        // Обработчик проверки статуса
        server.createContext("/status", WebUi::handleStatus);
        // Запуск сервера
        server.start();
        // Сообщение в консоль
        System.out.println("WebUI: http://localhost:8080");
    }

    // Отдача HTML-страницы
    private static void handleIndex(HttpExchange ex) throws IOException {
        // HTML с кнопкой запуска и опросом статуса
        String html = "<!DOCTYPE html><html><head><meta charset='UTF-8'><title>SauceDemo Tests</title></head><body>"
                + "<h1>SauceDemo автотесты</h1>"
                + "<button onclick=\"fetch('/run',{method:'POST'}).then(()=>alert('Запущено'))\">Запустить тесты</button>"
                + "<p id='s'>Статус: ожидание</p>"
                + "<script>setInterval(()=>fetch('/status').then(r=>r.text()).then(t=>document.getElementById('s').innerText='Статус: '+t),2000)</script>"
                + "</body></html>";
        // Отправка ответа
        send(ex, 200, html);
    }

    // Запуск прогона тестов
    private static void handleRun(HttpExchange ex) throws IOException {
        // Если уже выполняется — ответ без запуска
        if (running) { send(ex, 200, "уже выполняется"); return; }
        // Установка флага
        running = true;
        // Запуск в отдельном потоке
        new Thread(() -> {
            try {
                // Команда прогона тестов и запуска отчёта Allure
                ProcessBuilder pb = new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "allure:serve");
                // Рабочий каталог — корень проекта
                pb.directory(new File("."));
                // Перенаправление вывода в консоль
                pb.inheritIO();
                // Запуск и ожидание завершения
                Process p = pb.start();
                p.waitFor();
            } catch (Exception e) {
                // Вывод ошибки
                e.printStackTrace();
            } finally {
                // Сброс флага
                running = false;
            }
        }).start();
        // Немедленный ответ клиенту
        send(ex, 200, "запущено");
    }

    // Отдача текущего статуса
    private static void handleStatus(HttpExchange ex) throws IOException {
        // Текст статуса зависит от флага
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    // Вспомогательный метод отправки ответа
    private static void send(HttpExchange ex, int code, String body) throws IOException {
        // Кодирование тела в UTF-8
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        // Заголовок типа содержимого
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        // Отправка заголовков
        ex.sendResponseHeaders(code, bytes.length);
        // Запись тела
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

    private static void handleRun(HttpExchange ex) throws IOException {
        if (running) { send(ex, 200, "уже выполняется"); return; }
        // Добавлено: чтение тела POST-запроса в строку
        String body = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        // Добавлено: значение параметра tests из тела, по умолчанию пустая строка
        String tests = "";
        // Добавлено: разбор тела запроса на пары ключ=значение
        for (String pair : body.split("&")) {
            // Добавлено: разделение пары по знаку равенства
            String[] kv = pair.split("=", 2);
            // Добавлено: если ключ равен tests — декодирование значения
            if (kv.length == 2 && kv[0].equals("tests")) {
                // Добавлено: декодирование URL-кодированной строки в UTF-8
                tests = URLDecoder.decode(kv[1], StandardCharsets.UTF_8);
            }
        }
        // Добавлено: финальная переменная для передачи в лямбду
        final String testParam = tests;
        running = true;
        new Thread(() -> {
            try {
                // Старый код:
                // ProcessBuilder pb = new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "allure:serve");
                // Добавлено: если выбраны тесты — добавляется параметр -Dtest, иначе запускаются все
                ProcessBuilder pb = testParam.isEmpty()
                        // Добавлено: запуск всех тестов без -Dtest
                        ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "allure:serve")
                        // Добавлено: запуск только выбранных тестов через -Dtest
                        : new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "-Dtest=" + testParam, "allure:serve");
                pb.directory(new File("."));
                pb.inheritIO();
                Process p = pb.start();
                p.waitFor();
            } catch (Exception e) {
                e.printStackTrace();
            } finally {
                running = false;
            }
        }).start();
        send(ex, 200, "запущено");
    }

    private static void handleStatus(HttpExchange ex) throws IOException {
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    private static void send(HttpExchange ex, int code, String body) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

почему не проиходит повторный запуск?
Факт: в WebUi.java команда mvn clean test allure:serve запускается через ProcessBuilder и ожидается вызовом p.waitFor(). Факт: цель allure:serve запускает локальный веб-сервер и не завершается до нажатия Ctrl+C. Факт: p.waitFor() не возвращает управление, пока процесс Maven не завершён. Факт: сброс флага running в блоке finally происходит только после завершения процесса. Факт: при повторном запросе на /run флаг running равен true, и обработчик возвращает строку "уже выполняется" без запуска нового процесса. Факт: в HTML-скрипте вызов alert('Запущено') выполняется независимо от тела ответа /run. Факт: повторный запуск не происходит из-за незавершённого процесса allure:serve и флага running в значении true.

import com.sun.net.httpserver.HttpServer;

import java.nio.charset.StandardCharsets;

public class WebUi {

    private static volatile boolean running = false;

    public static void main(String[] args) throws Exception {
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/", WebUi::handleIndex);
        server.createContext("/run", WebUi::handleRun);
        server.createContext("/status", WebUi::handleStatus);
        server.start();
        System.out.println("WebUI: http://localhost:8080");
    }

    private static void handleIndex(HttpExchange ex) throws IOException {
        String html = "<!DOCTYPE html><html><head><meta charset='UTF-8'><title>SauceDemo Tests</title></head><body>"
                + "<h1>SauceDemo автотесты</h1>"
                + "<form id='f'>"
                + "<label><input type='checkbox' name='t' value='LoginTest#testSuccessfulLogin'> LoginTest.testSuccessfulLogin</label><br>"
                + "<label><input type='checkbox' name='t' value='ApiTest#testMainPageAvailability'> ApiTest.testMainPageAvailability</label><br>"
                + "<button type='submit'>Запустить выбранные</button>"
                + "</form>"
                + "<p id='s'>Статус: ожидание</p>"
                + "<script>"
                + "document.getElementById('f').onsubmit=function(e){e.preventDefault();"
                + "var v=[...document.querySelectorAll('input[name=t]:checked')].map(x=>x.value);"
                + "if(!v.length){alert('Выберите хотя бы один тест');return;}"
                // Старый код: + "fetch('/run',{method:'POST',headers:{'Content-Type':'application/x-www-form-urlencoded'},body:'tests='+encodeURIComponent(v.join(','))}).then(()=>alert('Запущено'));};"
                // Добавлено: убран вызов alert('Запущено') для устранения избыточного окна подтверждения
                + "fetch('/run',{method:'POST',headers:{'Content-Type':'application/x-www-form-urlencoded'},body:'tests='+encodeURIComponent(v.join(','))});};"
                + "setInterval(()=>fetch('/status').then(r=>r.text()).then(t=>document.getElementById('s').innerText='Статус: '+t),2000);"
                + "</script>"
                + "</body></html>";
        send(ex, 200, html);
    }

    private static void handleRun(HttpExchange ex) throws IOException {
        if (running) { send(ex, 200, "уже выполняется"); return; }
        String body = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        String tests = "";
        for (String pair : body.split("&")) {
            String[] kv = pair.split("=", 2);
            if (kv.length == 2 && kv[0].equals("tests")) {
                tests = URLDecoder.decode(kv[1], StandardCharsets.UTF_8);
            }
        }
        final String testParam = tests;
        running = true;
        new Thread(() -> {
            try {
                ProcessBuilder testPb = testParam.isEmpty()
                        ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test")
                        : new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "-Dtest=" + testParam);
                testPb.directory(new File("."));
                testPb.inheritIO();
                Process testP = testPb.start();
                testP.waitFor();

                ProcessBuilder reportPb = new ProcessBuilder("cmd", "/c", "mvn", "allure:report");
                reportPb.directory(new File("."));
                reportPb.inheritIO();
                Process reportP = reportPb.start();
                reportP.waitFor();

                File reportFile = new File("target/site/allure-maven-plugin/index.html");
                if (reportFile.exists() && Desktop.isDesktopSupported()) {
                    Desktop.getDesktop().browse(reportFile.toURI());
                }
            } catch (Exception e) {
                e.printStackTrace();
            } finally {
                running = false;
            }
        }).start();
        send(ex, 200, "запущено");
    }

    private static void handleStatus(HttpExchange ex) throws IOException {
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    private static void send(HttpExchange ex, int code, String body) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

        // Добавлено: обязательный аргумент для работы браузера в контейнере без графического интерфейса

        options.addArguments("--disable-dev-shm-usage");
        return new ChromeDriver(options);
    }

    }

Факт: ошибка возникла потому, что в предыдущей версии WebUi.java из команд запуска был удален вызов cmd /c. В Windows файл mvn является пакетным файлом (mvn.cmd), и Java не может запустить его напрямую без cmd /c.
Факт: для корректной работы как в Windows, так и в Linux-контейнере требуется условное добавление cmd /c на основе определения операционной системы.

import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpExchange;
import java.net.InetSocketAddress;
import java.io.*;
import java.nio.charset.StandardCharsets;
import java.net.URLDecoder;
import java.awt.Desktop;

public class WebUi {

    private static volatile boolean running = false;

    public static void main(String[] args) throws Exception {
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/", WebUi::handleIndex);
        server.createContext("/run", WebUi::handleRun);
        server.createContext("/status", WebUi::handleStatus);
        server.start();
        System.out.println("WebUI: http://localhost:8080");
    }

    private static void handleIndex(HttpExchange ex) throws IOException {
        String html = "<!DOCTYPE html><html><head><meta charset='UTF-8'><title>SauceDemo Tests</title></head><body>"
                + "<h1>SauceDemo автотесты</h1>"
                + "<form id='f'>"
                + "<label><input type='checkbox' name='t' value='LoginTest#testSuccessfulLogin'> LoginTest.testSuccessfulLogin</label><br>"
                + "<label><input type='checkbox' name='t' value='ApiTest#testMainPageAvailability'> ApiTest.testMainPageAvailability</label><br>"
                + "<button type='submit'>Запустить выбранные</button>"
                + "</form>"
                + "<p id='s'>Статус: ожидание</p>"
                + "<script>"
                + "document.getElementById('f').onsubmit=function(e){e.preventDefault();"
                + "var v=[...document.querySelectorAll('input[name=t]:checked')].map(x=>x.value);"
                + "if(!v.length){alert('Выберите хотя бы один тест');return;}"
                + "fetch('/run',{method:'POST',headers:{'Content-Type':'application/x-www-form-urlencoded'},body:'tests='+encodeURIComponent(v.join(','))});};"
                + "setInterval(()=>fetch('/status').then(r=>r.text()).then(t=>document.getElementById('s').innerText='Статус: '+t),2000);"
                + "</script>"
                + "</body></html>";
        send(ex, 200, html);
    }

    private static void handleRun(HttpExchange ex) throws IOException {
        if (running) { send(ex, 200, "уже выполняется"); return; }
        String body = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        String tests = "";
        for (String pair : body.split("&")) {
            String[] kv = pair.split("=", 2);
            if (kv.length == 2 && kv[0].equals("tests")) {
                tests = URLDecoder.decode(kv[1], StandardCharsets.UTF_8);
            }
        }
        final String testParam = tests;
        running = true;
        new Thread(() -> {
            try {
                // Добавлено: определение операционной системы для выбора правильного синтаксиса запуска mvn
                boolean isWindows = System.getProperty("os.name").toLowerCase().contains("win");

                ProcessBuilder testPb;
                if (testParam.isEmpty()) {
                    // Добавлено: для Windows используется cmd /c, для Linux — прямой вызов mvn
                    testPb = isWindows 
                        ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test") 
                        : new ProcessBuilder("mvn", "clean", "test");
                } else {
                    // Добавлено: аналогично для запуска конкретных тестов
                    testPb = isWindows 
                        ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "-Dtest=" + testParam) 
                        : new ProcessBuilder("mvn", "clean", "test", "-Dtest=" + testParam);
                }
                testPb.directory(new File("."));
                testPb.inheritIO();
                Process testP = testPb.start();
                testP.waitFor();

                // Добавлено: условное создание процесса генерации отчета
                ProcessBuilder reportPb = isWindows 
                    ? new ProcessBuilder("cmd", "/c", "mvn", "allure:report") 
                    : new ProcessBuilder("mvn", "allure:report");
                reportPb.directory(new File("."));
                reportPb.inheritIO();
                Process reportP = reportPb.start();
                reportP.waitFor();

                File reportFile = new File("target/site/allure-maven-plugin/index.html");
                if (reportFile.exists() && Desktop.isDesktopSupported()) {
                    Desktop.getDesktop().browse(reportFile.toURI());
                }
            } catch (Exception e) {
                e.printStackTrace();
            } finally {
                running = false;
            }
        }).start();
        send(ex, 200, "запущено");
    }

    private static void handleStatus(HttpExchange ex) throws IOException {
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    private static void send(HttpExchange ex, int code, String body) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpExchange;
import java.net.InetSocketAddress;
import java.io.*;
import java.nio.charset.StandardCharsets;
import java.net.URLDecoder;

public class WebUi {

    private static volatile boolean running = false;
    // Добавлено: объект для накопления логов выполнения процесса
    private static final StringBuilder logBuffer = new StringBuilder();

    public static void main(String[] args) throws Exception {
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/", WebUi::handleIndex);
        server.createContext("/run", WebUi::handleRun);
        server.createContext("/status", WebUi::handleStatus);
        // Добавлено: контекст для получения логов
        server.createContext("/logs", WebUi::handleLogs);
        server.start();

    private static void handleIndex(HttpExchange ex) throws IOException {
        String html = "<!DOCTYPE html><html><head><meta charset='UTF-8'><title>SauceDemo Tests</title>"
                + "<style>pre{background:#f4f4f4;padding:10px;height:400px;overflow:auto;}</style></head><body>"
                + "<h1>SauceDemo автотесты</h1>"
                + "<form id='f'>"

                + "<label><input type='checkbox' name='t' value='ApiTest#testMainPageAvailability'> ApiTest.testMainPageAvailability</label><br>"

                // Добавлено: элемент для отображения логов
                + "<pre id='log'></pre>"

                // Добавлено: получение ссылки на кнопку
                + "var btn=document.getElementById('runBtn');"
                + "document.getElementById('f').onsubmit=function(e){e.preventDefault();"

                + "fetch('/run',{method:'POST',headers:{'Content-Type':'application/x-www-form-urlencoded'},body:'tests='+encodeURIComponent(v.join(','))});};"
                // Добавлено: обновление статуса, блокировка кнопки и вывод логов
                + "setInterval(function(){"
                + "fetch('/status').then(r=>r.text()).then(t=>{"
                + "document.getElementById('s').innerText='Статус: '+t;"
                // Добавлено: блокировка кнопки при статусе 'выполняется'
                + "btn.disabled=(t==='выполняется');"
                + "});"
                // Добавлено: запрос логов и прокрутка вниз
                + "fetch('/logs').then(r=>r.text()).then(t=>{var l=document.getElementById('log');l.innerText=t;l.scrollTop=l.scrollHeight;});"
                + "},2000);"
                + "</script>"
                + "</body></html>";
        send(ex, 200, html);
    }

    private static void handleRun(HttpExchange ex) throws IOException {
        if (running) { send(ex, 200, "уже выполняется"); return; }
        String body = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        String tests = "";
        for (String pair : body.split("&")) {
            String[] kv = pair.split("=", 2);
            if (kv.length == 2 && kv[0].equals("tests")) {
                tests = URLDecoder.decode(kv[1], StandardCharsets.UTF_8);
            }
        }
        final String testParam = tests;
        running = true;
        // Добавлено: очистка логов перед новым запуском
        synchronized (logBuffer) {
            logBuffer.setLength(0);
        }
        
        new Thread(() -> {
            try {
                boolean isWindows = System.getProperty("os.name").toLowerCase().contains("win");

                ProcessBuilder pb;
                if (testParam.isEmpty()) {
                    pb = isWindows
                            ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "allure:serve")
                            : new ProcessBuilder("mvn", "clean", "test", "allure:serve");
                } else {
                    pb = isWindows
                            ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "-Dtest=" + testParam, "allure:serve")
                            : new ProcessBuilder("mvn", "clean", "test", "-Dtest=" + testParam, "allure:serve");
                }
                pb.directory(new File("."));
                // Добавлено: перенаправление потока ошибок в основной поток для перехвата
                pb.redirectErrorStream(true);
                Process p = pb.start();
                
                // Добавлено: чтение вывода процесса построчно в отдельном потоке
                try (BufferedReader reader = new BufferedReader(new InputStreamReader(p.getInputStream(), StandardCharsets.UTF_8))) {
                    String line;
                    while ((line = reader.readLine()) != null) {
                        // Добавлено: синхронизированное добавление строки в буфер логов
                        synchronized (logBuffer) {
                            logBuffer.append(line).append("\n");
                        }
                        System.out.println(line);
                    }
                }
                p.waitFor();
            } catch (Exception e) {
                e.printStackTrace();
            } finally {
                running = false;
            }
        }).start();
        send(ex, 200, "запущено");
    }

    private static void handleStatus(HttpExchange ex) throws IOException {
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    // Добавлено: обработчик возврата накопленных логов
    private static void handleLogs(HttpExchange ex) throws IOException {
        String currentLogs;
        // Добавлено: синхронизированное чтение логов для предотвращения конфликтов
        synchronized (logBuffer) {
            currentLogs = logBuffer.toString();
        }
        send(ex, 200, currentLogs);
    }

    private static void send(HttpExchange ex, int code, String body) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

запуск через контейнер возможен только headless?
Запуск браузера в Docker-контейнере не ограничивается только headless-режимом. Существует возможность запуска с графическим интерфейсом (headed mode), но для этого требуется эмуляция дисплея, поскольку в контейнере по умолчанию отсутствует физический экран.

Основные варианты для запуска в режиме с графическим интерфейсом:

Использование Xvfb (X Virtual Framebuffer): Это виртуальный дисплейный сервер, который эмулирует экран в памяти. Браузер запускается в обычном режиме, но выводит графику в виртуальный буфер. В официальных образах Selenium (например, selenium/standalone-chrome) поддержка Xvfb уже встроена, и её можно активировать с помощью переменной окружения SE_START_XVFB=true.

Использование VNC для удаленного доступа: Официальные Docker-образы Selenium также поддерживают VNC. Вы можете подключиться к контейнеру через VNC-клиент и видеть графический интерфейс браузера в реальном времени.

Комбинация Xvfb и VNC: Этот подход позволяет запускать браузер в headed-режиме внутри контейнера и одновременно просматривать его через VNC.

В вашем текущем Dockerfile используется базовый образ maven:3.9.6-eclipse-temurin-17 и устанавливается google-chrome-stable, но Xvfb не устанавливается и не настраивается. Именно поэтому браузер не может запуститься без флага --headless.

Zephyr, Postman , DBeaver , NATS , OpenSearch
Java 21, Playwright , Rest Assured, JDBI , JUnit 5, Allure - коротко расскажи про каждую. между описаниями делай пустую строку
Zephyr — это инструмент управления тестированием, который тесно интегрируется с Jira и позволяет планировать, отслеживать и управлять тестовыми сценариями, планами и циклами непосредственно в рабочем пространстве Jira.

Postman — это платформа для работы с API, предоставляющая инструменты для создания, отправки, тестирования, документирования и совместной работы с HTTP-запросами и коллекциями.

DBeaver — это бесплатный универсальный инструмент с открытым исходным кодом для управления базами данных, который поддерживает широкий спектр СУБД, включая PostgreSQL, MySQL, SQLite и другие.

NATS — это высокопроизводительная, легковесная система обмена сообщениями с открытым исходным кодом, предназначенная для построения распределенных систем и поддерживающая шаблоны публикации/подписки и запроса/ответа.

OpenSearch — это распределенный поисковый и аналитический пакет с открытым исходным кодом, основанный на Apache Lucene и предназначенный для полнотекстового поиска, аналитики логов и мониторинга приложений.

Java 21 — это LTS-версия платформы Java, которая включает такие новые возможности, как виртуальные потоки (Virtual Threads), сопоставление с образцом для switch и записи (Record Patterns).

Playwright — это фреймворк для автоматизации браузеров с открытым исходным кодом от Microsoft, который позволяет управлять браузерами Chromium, Firefox и WebKit через единый API для тестирования веб-приложений.

    private static void handleRun(HttpExchange ex) throws IOException {
        if (running) { send(ex, 200, "уже выполняется"); return; }
        String body = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        String tests = "";
        for (String pair : body.split("&")) {
            String[] kv = pair.split("=", 2);
            if (kv.length == 2 && kv[0].equals("tests")) {
                tests = URLDecoder.decode(kv[1], StandardCharsets.UTF_8);
            }
        }
        final String testParam = tests;
        running = true;
        synchronized (logBuffer) {
            logBuffer.setLength(0);
        }

        new Thread(() -> {
            try {
                boolean isWindows = System.getProperty("os.name").toLowerCase().contains("win");

                ProcessBuilder testPb;
                if (testParam.isEmpty()) {
                    testPb = isWindows
                            ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test")
                            : new ProcessBuilder("mvn", "clean", "test");
                } else {
                    testPb = isWindows
                            ? new ProcessBuilder("cmd", "/c", "mvn", "clean", "test", "-Dtest=" + testParam)
                            : new ProcessBuilder("mvn", "clean", "test", "-Dtest=" + testParam);
                }
                testPb.directory(new File("."));
                testPb.redirectErrorStream(true);
                Process p = testPb.start();

                try (BufferedReader reader = new BufferedReader(new InputStreamReader(p.getInputStream(), StandardCharsets.UTF_8))) {
                    String line;
                    while ((line = reader.readLine()) != null) {
                        synchronized (logBuffer) {
                            logBuffer.append(line).append("\n");
                        }
                        System.out.println(line);
                    }
                }
                p.waitFor();

                ProcessBuilder reportPb = isWindows
                        ? new ProcessBuilder("cmd", "/c", "mvn", "allure:report")
                        : new ProcessBuilder("mvn", "allure:report");
                reportPb.directory(new File("."));
                reportPb.redirectErrorStream(true);
                Process rp = reportPb.start();

                try (BufferedReader reader = new BufferedReader(new InputStreamReader(rp.getInputStream(), StandardCharsets.UTF_8))) {
                    String line;
                    while ((line = reader.readLine()) != null) {
                        synchronized (logBuffer) {
                            logBuffer.append(line).append("\n");
                        }
                        System.out.println(line);
                    }
                }
                rp.waitFor();

            } catch (Exception e) {
                e.printStackTrace();
            } finally {
                running = false;
            }
        }).start();
        send(ex, 200, "запущено");
    }

    private static void handleStatus(HttpExchange ex) throws IOException {
        send(ex, 200, running ? "выполняется" : "ожидание");
    }

    private static void handleLogs(HttpExchange ex) throws IOException {
        String currentLogs;
        synchronized (logBuffer) {
            currentLogs = logBuffer.toString();
        }
        send(ex, 200, currentLogs);
    }

    private static void handleAllure(HttpExchange ex) throws IOException {
        String path = ex.getRequestURI().getPath();
        if (path.equals("/allure") || path.equals("/allure/")) {
            path = "/allure/index.html";
        }
        File file = new File("target/site/allure-maven-plugin" + path.replace("/allure", ""));
        if (!file.exists() || file.isDirectory()) {
            send(ex, 404, "Not found");
            return;
        }

        String mime = "text/plain";
        if (path.endsWith(".html")) mime = "text/html";
        else if (path.endsWith(".js")) mime = "application/javascript";
        else if (path.endsWith(".css")) mime = "text/css";
        else if (path.endsWith(".png")) mime = "image/png";
        else if (path.endsWith(".svg")) mime = "image/svg+xml";
        else if (path.endsWith(".woff2")) mime = "font/woff2";
        else if (path.endsWith(".woff")) mime = "font/woff";
        else if (path.endsWith(".ttf")) mime = "font/ttf";
        else if (path.endsWith(".json")) mime = "application/json";

        byte[] bytes = Files.readAllBytes(file.toPath());
        ex.getResponseHeaders().add("Content-Type", mime);
        ex.sendResponseHeaders(200, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }

    private static void send(HttpExchange ex, int code, String body) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().add("Content-Type", "text/html; charset=UTF-8");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
